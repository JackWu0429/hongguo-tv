# 红果短剧 TV

独立 Android TV 客户端项目，以 [hongguo-player](https://github.com/yangbin1322/hongguo-player) 的 Mac 发布版为功能和布局参考，采用 Android 壳与 Go 核心的实现方式。

本仓库为私有仓库。当前版本包含可启动的 Go 本地服务、Android TV 壳、Mac 风格推荐页、红果分类/详情接口和 APK 内置播放链路，并由 GitHub Actions 构建。

## 项目方向

- 目标是复刻完整客户端的功能，而不是把现有 Lampa 插件包装为 APK。
- 保留 Mac 版的左侧栏和右侧内容区；推荐页以视频流为主体。
- 为 TV 重新设计遥控器焦点、面板回退和播放状态恢复。
- Android 壳、Go 编译和打包流程参考 `aston314/vidsrc-local-proxy`；播放协议则复用了已验证的 MiniReel 签名与 CENC 解密实现。
- APK 在 GitHub Actions 上编译，覆盖 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。

## 功能范围

推荐、找剧、分类、排行榜、新剧、详情、选集、连续播放、同系列、下一季、历史、收藏、点赞、预约、账号登录、评论、弹幕，以及原版提供的播放控制与下载能力。

范围表示复刻目标，不代表上述功能已经实现。没有源码的接口与内部算法必须逐项验证，尤其是账号、分季、弹幕和下载。

## 当前实现

- Go 服务默认监听 `127.0.0.1:8797`，避免与现有 8787 服务冲突。
- Android 壳通过前台服务启动 Go 进程，WebView 打开 Go 服务提供的 TV 页面。
- TV 页面包含 Mac 风格左侧栏、竖屏推荐视频流、找剧海报页、排行榜长卡列表、新剧海报页、详情选集和播放控制；方向键支持网格按行切换、榜单侧栏与操作按钮切换，播放返回原卡片并保留滚动位置。
- Go 核心提供分类、搜索、热播榜、详情、播放信息 API，并在同一进程中提供 MiniReel 播放解析、`spade_a` 密钥解码、CENC AES-CTR 清晰化、临时 MP4 缓存和 Range 媒体路由。
- 排行榜、新剧、上新日历、推荐四频道和预约使用已核对的红果 JSON API。榜单选项、日历日期由接口提供。HEIC 保留签名原地址，同时提供经过实测的官网 JPEG CDN 地址供 WebView 显示。
- 找剧、榜单、新剧、日历、预约、评论和历史/收藏/点赞统一滚动追加，没有加载更多按钮。推荐剩余 3 项时只加载内容数据，不提前解析媒体；追加保留 DOM、焦点和滚动位置，失败可重试原页。
- 关键词搜索已支持 App 分页结构，但匿名请求空响应时回退官网单批数据；滚动仅渐进展示该批结果，不伪造远程下一页。长度筛选尚未确认参数。
- 日历可以预约和取消预约，我的预约区分已上线/待上线；关注和预约要求登录。预约写入仅 fixture 验证，真实账号仍待 APK 验收。
- APK 内置播放服务是唯一播放链路；不会在运行时调用 8787 或 57828，也不要求用户另行部署服务。缓存目录由 Android 壳传入应用私有 cache 目录，默认按 TTL 和总大小清理。
- 历史、收藏和点赞保存在设备上的 Go 记录文件，服务重启后可恢复；历史最多 200 部，收藏/点赞各最多 300 部。真正开始播放才写历史，每 10 秒及暂停/退出时保存进度；重新打开可恢复集数和时间位置，支持自动下一集。清空单个记录列表不会清空其它列表，清空全部前有确认弹窗。
- 本季最后一集结束后，通过官方季关系接口确认当前季并选择最近的可播放下一季，从第一集开始。排除禁播、零集和缺少首集的条目，不猜标题、不提前解析媒体。暂无下一季时推荐页转下一部，独立播放页停止；关系请求失败则暂停连续播放。跨季后选集、继续播放和历史更新到新剧，返回仍保留原卡片；退出页面或退后台会取消尚未完成的自动切换。
- 选集面板新增“系列剧”：使用官方完整系列列表，显示季标签、播放中/继续播放及待上线预约状态。遥控器逐行滚动，一键切季保留面板、进度和原页面返回位置；登录后可以预约或取消待上线季，游客只提示登录。浏览列表不解析媒体。详见 [系列剧说明](docs/series-seasons.md)。
- 已接入手机号验证码登录、上行短信验证分支、会话恢复及账号退出；完整签名在 Go 内独立实现，固定向量与参考算法匹配，匿名用户接口已取得有效响应。账号 Cookie/Token 只存于应用私有目录，不传给页面或外部签名服务。真实手机号登录仍待在 APK 中验收。
- 登录后使用独立的账号记录，同步云端收藏、历史和观看进度；取消收藏会提交云端。先拉取并比较进度时间，再上传本机待同步操作；失败保留队列，重启可恢复。登录前记录保留在本机，退出后恢复；本机清空不批量删除云端，点赞仅本机保存。协议、ID/时间单位、失败/取消和焦点已用 fixture 验证，尚未宣称真实账号云同步成功。
- 播放控制支持暂停、按 10 秒快进/快退、进度定位、倍速、音量与全屏布局；倍速/音量/清晰度偏好保存在本机。清晰度按当前集实际档位切换，保留时间和暂停状态，失败保留原视频；关闭面板、离开页面或后台取消等待。控制区分为进度行和按钮行，面板限定焦点；开始播放后空闲 4 秒隐藏控件，确认键显示控件。后台暂停并保存进度，返回前台不会自行继续播放。
- Android 返回键先交由页面按面板、控件、全屏和上一页处理，根侧栏再显示退出确认；播放/暂停、快进/快退媒体键已接入页面桥接。实际遥控器行为仍待设备验收。
- 当前集评论使用 Mac 风格右侧栏，支持评论/回复滚动分页、登录后发表、回复、点赞及确认删除本人评论。底部输入区固定，失败保留草稿；发送成功提示等待审核，不自动重试写入。弹幕按当前时间的 30 秒窗口读取，可独立开关并发送，暂停/seek/换集时暂停或清理旧弹幕。真实账号写操作仍待验收。详见 [播放操作](docs/player-actions.md) 和 [接口与分页盘点](docs/lists-pagination.md)。
