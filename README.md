# 红果短剧 TV

独立 Android TV 客户端项目，以 [hongguo-player](https://github.com/yangbin1322/hongguo-player) 的 Mac 发布版为功能和布局参考，采用 Android 壳与 Go 核心的实现方式。

本仓库为私有仓库。当前版本包含可启动的 Go 本地服务、Android TV 壳、Mac 风格推荐页、红果分类/详情接口和 APK 内置播放链路，并由 GitHub Actions 构建。

## 项目方向

- 目标是复刻完整客户端的功能，而不是把现有 Lampa 插件包装为 APK。
- 保留 Mac 版的左侧栏和右侧内容区；推荐页以视频流为主体。
- 为 TV 重新设计遥控器焦点、面板回退和播放状态恢复。
- Android 壳、Go 编译和打包流程参考 `aston314/vidsrc-local-proxy`；播放协议则复用了已验证的 MiniReel 签名与 CENC 解密实现。
- APK 在 GitHub Actions 上编译，覆盖 `arm64-v8a`、`armeabi-v7a` 和 `x86_64`。

## 功能范围

推荐、找剧、分类、排行榜、新剧、详情、选集、连续播放、同系列、下一季、历史、收藏、点赞、预约、账号登录、评论、弹幕，以及原版提供的播放控制与下载能力。

范围表示复刻目标，不代表上述功能已经实现。没有源码的接口与内部算法必须逐项验证，尤其是账号、分季、弹幕和下载。

## 当前实现

- Go 服务默认监听 `127.0.0.1:8797`，避免与现有 8787 服务冲突。
- Android 壳通过前台服务启动 Go 进程，WebView 打开 Go 服务提供的 TV 页面。
- TV 页面包含 Mac 风格左侧栏、竖屏推荐视频流、找剧海报页、排行榜长卡列表、新剧海报页、详情选集和播放控制；方向键支持网格按行切换、榜单侧栏与操作按钮切换，播放返回原卡片并保留滚动位置。
- Go 核心提供分类、搜索、热播榜、详情、播放信息 API，并在同一进程中提供 MiniReel 播放解析、`spade_a` 密钥解码、CENC AES-CTR 清晰化、临时 MP4 缓存和 Range 媒体路由。
- 四个热播榜使用官网真实榜单；新剧通过分类 API 的 `online_time` 排序取得。HEIC 海报保留签名原地址，并提供经过实测的官网 JPEG CDN 地址供 WebView 显示。
- 找剧筛选面板、结果刷新和游标分页已接入真实分类 JSON API；新剧男频/女频也使用真实参数。Mac 截图中的长度筛选尚未取得参数。
- 上新日历、已上线/待上线预约和其它榜单已提供页面结构与遥控器焦点，未知接口显示“数据接入中”；不会用热播榜或最新剧列表冒充对应内容。
- APK 内置播放服务是唯一播放链路；不会在运行时调用 8787 或 57828，也不要求用户另行部署服务。缓存目录由 Android 壳传入应用私有 cache 目录，默认按 TTL 和总大小清理。
- 历史、收藏和点赞保存在设备上的 Go 记录文件，服务重启后可恢复；历史最多 200 部，收藏/点赞各最多 300 部。真正开始播放才写历史，每 10 秒及暂停/退出时保存进度；重新打开可恢复集数和时间位置，单季内支持自动下一集。清空单个记录列表不会清空其它列表，清空全部前有确认弹窗。
- 本机记录与账号同步分别处理：登录、云端收藏/点赞、分季关系和自动下一季仍待接入，不把本地状态当作账号操作成功。

## 后续工作

1. 建立原版页面与方法清单，记录可观察的输入、输出和行为。
2. 运行原版采集未知接口的请求，保存经过脱敏的响应样本。
3. 确认 Android 壳、Go 进程通信和播放实现。
4. 开发 TV 页面与 Go 核心，接入 GitHub Actions 构建。
5. 逐项验收原版功能和遥控器操作。

原仓库发布的是编译产物；本项目重新实现客户端，不具备从原仓库源码直接交叉编译的条件。
