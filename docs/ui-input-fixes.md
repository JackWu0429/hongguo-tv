## 推荐

既有推荐接口已经返回列表及分页游标，缺失的是输入交互。仍使用 `/api/v1/lists/recommend`，上游为 `bookmall/cell/change/v`；非默认频道先 `bookmall/tab/v`，再使用返回的 cell/plan 继续分页。没有另造“上一条 / 下一条”接口。

- 视频区域拥有焦点时，遥控器上键上一条、下键下一条，控件显示时也生效；长按重复事件不连续跨剧。左右键仍进入侧栏 / 操作按钮。
- 视频区域向上滑动下一条、向下滑动上一条，过滤短距离、横向、多指、超时及已经切换后的旧手势。按钮与弹窗不触发切剧。滚轮下滚下一条、上滚上一条，累积阈值并忽略同一触控板手势的惯性。
- 第一条向上保持第一条；末端加载下一页并检查频道分页 generation，旧频道响应不得切换当前频道。独立剧播放页、弹窗及后台不响应推荐手势。
- 加载推荐时只显示“红果短剧 TV / 正在读取推荐”，隐藏上一部的海报、视频和播放控件；移除无数据时的“查看详情”及“接口接入中 / 当前版本先验证…”文字。失败 / 空列表 / 未登录关注频道仍显示对应状态。

## 找剧

筛选按钮原来调用了缺失的 `selectSearchFilter`，所以没有发新请求。新增处理函数更新选中状态并重置共享分页器，继续直接使用红果分类 JSON API，不换接口。

切体裁时重新读取筛选项，清除上一体裁的主题 / 设定 / 背景；保留排序等通用条件。翻页保留选择，切条件清除旧 offset/session/shown，迟到回复不会覆盖新的选择。焦点留在所选条件，返回列表后滚动加载不重建已有卡片。
