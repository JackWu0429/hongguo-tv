# 观看历史筛选

历史页提供「全部」「未看完」「已看完」。选中态与遥控器焦点分开，进入历史时默认「全部」，离开页面或播放返回时保留本次会话的选择。账号身份变化后恢复「全部」。

## 判断规则

已有观看时间、已知总集数、最近观看集数达到总集数，并且该集的 `completed` 为真，才能归入「已看完」。该标记表示一集自然播放结束，因此中间集播放结束不代表整部看完。多季短剧按其独立 `series_id` 判断，不表示整个系列看完。

刚进入最后一集、总集数未知、云端旧记录没有结束标记，均保留在「未看完」。云端同步的 `duration` 可能是整部剧总时长，不用其与 `position` 的比值猜测完成状态。重新开始最后一集会更新当前进度，恢复「未看完」。

## 展示与操作

先筛选完整本机/同步记录，再按观看时间排序及每批 20 部滚动加载，不设记录总数上限。切换筛选重置当前批次和滚动位置；播放返回保留筛选、已显示数量及仍存在的卡片焦点。若卡片因观看状态改变退出当前筛选，焦点回到列表中的可用卡片或当前筛选按钮。

方向键在筛选行左右移动，左边界进入侧边栏；向下进入卡片，卡片首行向上返回当前筛选。空列表向下可进入「去找剧」，向上返回筛选。筛选不写入存储、不调用云端修改接口，也不影响收藏/点赞。

「管理」移除当前选定的历史记录；「清空」仍为清空全部历史，保留原来的确认弹窗和明确的范围说明。

## 验证

`tests/history-filters.test.cjs` 覆盖最后一集与中间集结束、旧云端记录、排序和数据不变、收藏/点赞隔离、筛选前分页、完成及重看后的状态变化。隔离浏览器使用模拟记录与本地媒体，检查 960×540、1280×720、1920×1080 布局及遥控器导航、分页到底、空结果和播放返回。禁用新 WebView API 和 Flex gap，验证旧 WebView 兼容路径；未替代 Android 6 实机验收。
