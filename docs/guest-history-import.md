# 合并登录前观看历史

在“我的”→“云同步”中点击“合并登录前记录”，将本机游客观看历史加入当前登录账号。已登录用户也可以操作；登录时不会自动导入。

- 按 `series_id` 去重，按原观看更新时间保留较新的进度。同时间保留账号记录；不按集号大小判断。首次导入的旧记录不会被改写成当前时间。
- 只合并观看历史、集号和播放进度；不导入游客收藏、点赞，账号原有收藏和点赞保持不变。
- 原游客库不改动。账号库中原子保存历史、待上传操作和每部剧的导入时间标记。导入标记保留在内部同步状态，不通过历史接口暴露。
- 再次点击或重启不会重复导入。已经导入后删除/清空的历史不会因再次合并而恢复，即使本机排除标记被淘汰；游客之后产生的新观看记录可以再次合并。
- 合并后立即刷新本机记录，并进入现有云同步流程。先完整读取云端，云端较新的进度优先；上传失败保留队列并重试，历史和进度两项上报都成功才确认。
- 写盘失败不会提交任何记录、队列或导入标记。请求必须携带当前账号 ID，退出或换账号后的迟到请求会拒绝。
- 待同步队列仍最多 2000 项，历史显示总量不限。队列满时提示先同步；超过容量的合并保留尚未导入部分并明确显示剩余条数，完成同步后可继续合并，不丢记录、不标记未处理项为已导入。

遥控器右栏路线为：立即同步 → 合并登录前记录 → 检查更新；向上按相反顺序返回，向左回账号栏。没有候选时按钮禁用，合并完成后移到可操作的同步按钮或账号按钮。手机号/验证码数字键盘与扫码输入链路保持不变。

测试覆盖进度冲突、原时间、去重、归属、原文件保留、重复及重启、删除与清空、防复活、写盘失败、队列容量与剩余项、云端较新、上传重试及并发新播放。浏览器使用真实后端与隔离数据，不执行真实账号合并。

本机隔离页面：`HONGGUO_GUEST_HISTORY_UI_FIXTURE=1 go test ./core/cmd/hongguotv -run '^TestGuestHistoryBrowserFixture$' -v -timeout 30m`，访问 `http://127.0.0.1:19697/`。仅测试文件提供，未包含在 APK。
