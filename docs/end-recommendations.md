# 卡片播放结束后的相关推荐

从找剧、排行榜、历史等卡片进入的独立播放页，在最后一集结束且没有可连续播放的下一季时，从底部淡入一行相关推荐。数据直接使用当前剧 `/api/v1/series/detail` 返回的 `related`，与选集弹窗共用同一份详情；不以首页推荐填充。去掉本剧、重复项、未上线或明确不可播放的项，最多显示 20 部；没有有效项时保留原完成提示，不出现空面板。

普通下一集、可播放的下一季仍按原逻辑自动续播。下一季待上线时，先完成原有预约确认，再展示相关推荐。详情不完整、请求失败、账号或播放会话已变化时，不将其误判为完播。推荐频道的切剧逻辑保持原样。

## 遥控与返回

- 出现时焦点落在第一张卡片；左右移动，超出可视范围时横向滚动，到边缘停止。
- 上键进入关闭按钮，下键返回刚才选中的卡片；Tab 在关闭按钮和所选卡片间切换。
- 确认直接播放所选剧，沿用原有历史续播和返回来源；展示列表时不预取这些剧的视频。
- 返回或关闭只收起这一行，显示底部控件，焦点落到可见的“选集”按钮，不退出全屏或播放页，也不重播刚结束的影片。同一播放会话关闭后不会再次自动弹出。
- 选集、预约、评论等弹窗打开时，或用户仍在操作其他控件时暂缓展示，回到播放区域后再显示。
- 换源、离开播放页、切账号和进入后台会清理推荐状态；清理前若焦点在推荐行，先恢复到播放区域，避免焦点随卡片被移除。窗口缩放时确保选中的卡片仍可见。

面板沿用普通海报的焦点边框，单行横向滚动；960×540 逻辑视口使用较小海报，底部控件在面板展开时隐藏。动画只影响面板显示，不延迟正常切集或起播。

## 首张卡片自动播放

推荐行展开且第一张海报已显示后，第一张卡片右上角显示紧凑的圆角数字角标（30、29、28…），不显示“秒”或“自动播放”文字。只对首张卡片计时；图片失败或超过 2.5 秒仍未返回时，以预留的海报占位作为可用卡片，避免无限等待。面板动画结束事件有兼容超时，随后经过绘制回调再启动完整的 30 秒。

倒计时使用经过的时间计算剩余秒数，默认使用单调时钟。到期时重新核对当前播放会话、账号、页面、前台状态、焦点和弹窗状态，再走与手动确认相同的选卡入口，因此沿用历史续播且只播放一次。没有相关数据、尚在预约确认或推荐行未展示时不计时。

方向键、Tab、手动确认、媒体键、焦点离开首张卡片，以及鼠标按下/滚轮/触摸浏览，都会永久取消本次倒计时并隐藏角标。回到第一张不重启；其他卡片不自动计时。关闭、换源、切账号、离页、窗口失焦和进入后台也会取消，旧定时器与迟到的图片/动画回调不能启动新的播放。即使后台清理后收到重复的 ended 事件，同一播放对象也不能重新弹行或重开倒计时。

## 验证

`tests/end-recommendations.test.cjs` 覆盖数据过滤、预约与控件焦点延后、会话失效、关闭去重、确认播放、现代与旧式遥控按键、返回优先级及自动续播分支。

倒计时补充可控时钟回归：显示就绪之前不计时、完整 30 秒、每秒更新、用户取消后不重启、关闭/后台/账号失效、旧定时器污染新会话、计时延迟和手动选择与到期重叠。完整页面浏览器另验证真实等待 30 秒后的首卡播放、关闭后“选集”焦点的可见性与方向键/确认操作，以及滚轮/触摸/失焦取消、图片延迟和失败兜底。

隔离的完整页面浏览器验证使用本地合成 H.264 视频和固定 API 响应，覆盖自然完播、左右滚动、预约确认/取消、无数据、下一季自动播放、选择后的历史续播、原生返回桥接、离页后的迟到响应、后台焦点恢复和窗口缩放；同时在 960×540 与 1920×1080 下移除旧 WebView 缺失的 API 验证布局和输入兼容性。浏览器结果不代表实体 Android TV、MPV/Media3 原生视频层已通过实机验收。
