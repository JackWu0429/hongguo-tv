# 找剧：手机扫码与最近关键词

找剧搜索框保留，新增SVG扫码入口。临时局域网输入通道复用`/api/v1/number-input`并支持`kind=search`，手机普通文本表单输入/粘贴中文、字母、数字和空格；发送后回填并执行原搜索。最长100 UTF-16单元，空白规范化，拒绝空值及控制字符。手机号和验证码继续使用原严格数字验证。

扫码5分钟有效，只开放选定LAN地址上的随机端口与随机路径、独立表单校验字段；核心账号/播放/历史接口保持loopback。返回、切页、后台及刷新使旧会话失效，迟到响应按generation隔离；单次消费后清理端口和输入值。无LAN或输入通道失败时可返回原搜索框。

核心以`search-history.json`独立保存设备最近10个关键词，原子替换且限制条目与文本长度。与账号、云库、播放历史独立，不增加云写。`/api/v1/search-history`支持GET、POST(query)、DELETE；成功首屏（含空结果及重试成功）保存，重复前移，超过上限淘汰最旧。失败、取消、过时响应和后续分页不保存。损坏的关键词文件不阻止启动。

历史读取、增加和清空按队列执行，避免迟到读写复活清空条目。关键词单行横向滚动，选择即搜索，焦点重绘按关键词恢复。Down从搜索区域到历史，再进入筛选/结果；最左Left到侧栏，Up反向返回。清空复用确认弹窗，取消不改历史；清空成功恢复可用搜索区域。扫码弹窗隔离焦点，返回恢复入口，完成后沿用正常搜索焦点。

Android壳隐藏搜索按钮，输入框确认键搜索，Down进入扫码按钮；扫码Up回输入框、Down进历史/筛选，返回和空结果均选择可见入口。桌面浏览器仍显示搜索按钮。扫码和历史点选直接搜索。

保持ES5，新增CSS用flex和margin，避免依赖老Android不支持的grid/flex gap。浏览器旧API回归不能替代Android6实体遥控和手机同网验收。
