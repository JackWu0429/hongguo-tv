# 切剧加载显示

0.2.14 修复两处显示问题：旧 Android WebView 在重置视频源时可能闪出灰色视频矩形；全屏/控件隐藏时，下一部剧的 loading 有海报但没有剧名。

开始切剧时保留原来的全屏和控件状态，清除旧控件隐藏计时器，先进入准备状态、更新新剧名/集数与 loading，再暂停并重置旧视频源。视频层不仅 opacity=0，还使用 visibility:hidden；无 source 时也保持隐藏。推荐容器和媒体底色均为黑色，海报解码后按原比例 cover 显示，视频首帧可用后隐藏海报并恢复视频层。

控件隐藏时只覆盖准备状态的 hero-top-copy 可见性，不重新打开按钮、进度条、侧栏或整组控件。准备结束后名称恢复原来的隐藏状态；暂停和播放中缓冲仍保留视频画面，不重新进入海报准备状态。

2026-10-08 的隔离 fixture 使用本机生成的 MP4、不同的海报和延迟播放信息接口，强制 Chromium 44 缺失 API 与旧布局。验证重置 load() 时 video 的计算可见性为 hidden，新剧名先显示；播放后视频可见、海报隐藏，原控件隐藏状态保留。覆盖普通/全屏、正常播放、暂停、中途缓冲和快速上下切换，没有真实媒体解析或云端写入。

浏览器可以验证 DOM 状态和加载顺序，不能证明 Android 6 硬件视频层完全没有灰块。最终视觉需用正式 APK 复测。
