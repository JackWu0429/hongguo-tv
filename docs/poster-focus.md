# 普通海报卡片焦点（0.2.20）

找剧、搜索、新剧推荐、历史、收藏、点赞和已上线预约中的普通海报卡片，统一只在海报区域显示圆角白框。标题、集数或续播信息、日期、评分和进度条保持原来的排版；不再给整张卡片画框或放大整张卡片。

焦点和点击仍由原来的整张按钮接收，海报本身不新增焦点节点。共用 `.drama-poster` 的伪元素在海报框内画 3px 白框，兼容原生 `:focus` 和遥控器 `.is-focused`；即使图片正在加载或加载失败，白框仍显示。框内绘制避免搜索卡片 `overflow:hidden` 及旧 WebView 的圆角裁切问题，季数和集数角标保留。

新剧推荐与已上线预约使用 `publicationCard`，历史、收藏和点赞使用 `library-card`，找剧与搜索使用 `search-result-card`，均消费同一组规则。排行榜整行、待上线预约列表、日历行以及小缩略卡片保留各自的焦点样式。

继续支持最低 Android 6。隔离浏览器验证了 960×540、1280×720、1920×1080 的旧 grid/aspect/gap 布局，以及 1920×1080 的普通布局：白框范围与圆角、左右上下导航、滚动加载后的卡片、播放返回、原生与遥控焦点、图片加载及失败状态均通过。标题样式、卡片尺寸和季数角标保持一致，原卡片节点未被替换。82 项现有 Node 测试、12 项 Python 测试及 Go race/vet 通过；真实 Android 6 视觉需覆盖安装复测。
