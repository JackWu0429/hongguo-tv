# 名称、导航与媒体缓存（0.2.6）

正式版 Android 应用名称为“红果短剧”，调试版为“红果短剧 调试版”；包名和签名保持不变，覆盖安装保留原记录。48dp 矢量启动图标的背景改为圆角矩形，普通 icon 与 roundIcon 使用同一资源，Android 6 直接显示圆角图形。

侧栏使用 32px 图标、20px 文字和 54px 最低按钮高度。窄屏侧栏由 210px 调至 236px，以容纳“我的 / 登录”；高度不足时通过原有导航滚动到焦点。右侧操作最后一个弹幕按钮的 Down 到全屏，反向 Up 从全屏回弹幕，其他按钮保持原路径。

进度条焦点移除整个按钮的白框，改为当前位置 18px 白色圆点及轻微光晕；普通圆点为 10px。保留 44px 点击区域、左右 10 秒快进快退、slider 语义及当前时间读数。0% 和 100% 时圆点仍可见。

连接文字前使用 15px 内联 SVG，灰色表示连接中，绿色表示成功，红色表示失败。旧 WebView 使用 xlink:href，图标不参与焦点，也不重复播报。

## 缓存检查发现与修正

之前每个 Go 进程创建自己的随机 `minireel-go-*` 目录，但内存任务索引仅清理当前进程目录。因此反复重启后，旧目录可能留在 Android 的 cache/minireel 下。这不能仅凭当前进程 512 MiB 清理阈值就视为已解决。

Android/macOS 启动时初始化媒体缓存，每个新目录通过 `.core-lease` 文件持有内核排他锁。后续核心能够回收已退出进程的目录；仍被进程持有锁的目录保持可用。强制停止也会释放内核锁，不依赖正常退出回调。

升级前的无标记目录只在应用专用缓存位置、所有文件超过原有 2 小时 TTL、内容符合原媒体缓存结构时回收。最近目录保留到期，后续缓存操作最多每分钟复查一次。共享系统临时目录不迁移无标记目录；未知文件及符号链接保持不动。其他没有实现原生目录锁的平台继续保留原有进程内清理，避免误删并行进程数据。

当前进程继续按最近使用时间回收超过约 512 MiB 的完成文件，2 小时 TTL 保留，下载错误清理半成品。等待中的准备请求暂时保护所需文件。下载/解密文件及正在使用的内容可能使瞬时占用超过阈值，不能将其描述成整个缓存目录绝对不超过 512 MiB。

账号、历史及收藏位于独立 files/hongguo-tv，媒体清理不处理它们。

## 验证

Go 测试覆盖存活/退出核心目录、旧目录迁移保留条件、符号链接、启动与后续到期检查、512 MiB 淘汰和等待请求保护。文件体积测试使用稀疏文件，不下载真实视频。Go race/vet 及 32 项现有 JavaScript 测试通过。

旧 WebView API 模拟以实际视口 1280×720、1920×1080 核对图标/字体、登录项单行、弹幕↔全屏、全屏模式下的同一路径、进度条焦点、左右快进快退及首尾位置。浏览器 resize 受到宿主窗口高度限制，因此最终验收用明确的 viewport emulation 并核对 innerWidth/innerHeight。Android APK 仅由 GitHub 编译，最终核对原有证书、三 ABI、七个 UI 文件及编译后的圆角矢量图标。
