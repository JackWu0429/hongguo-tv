# 红果短剧 v0.2.109

## 修复

- 修复 Android 详情弹窗演员列表首项和末项的焦点高亮被滚动区域上下边缘裁剪的问题。
- 为旧版 Android WebView 增加演员网格焦点滚动安全距离，保证焦点环完整可见。
- 保留演员点击查看作品、弹窗布局和返回焦点恢复逻辑不变。

## 平台包

- Android 标准版：`hongguo-tv-0.2.109.apk`（versionCode 110）
- Android MPV 版：`hongguo-tv-mpv-0.2.109.apk`（versionCode 62）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.109-macos-universal.zip`、`hongguo-desktop-0.2.109-windows-x64.zip`（versionCode 48）
- Linux x86_64 AppImage 测试版
- LG webOS 实验版

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 与 webOS 仍属于平台测试包，实际兼容性取决于目标设备运行库、解码能力和型号。
