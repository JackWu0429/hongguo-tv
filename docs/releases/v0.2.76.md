# 红果短剧 v0.2.76

- 修复侧边栏顶部“推荐”项目的焦点框被裁切；滚动导航为焦点缩放和描边留出空间。
- 修复切换繁体中文或日文后，顶部核心服务状态仍显示旧语言的问题。
- Android 标准版和 MPV 版、macOS / Windows 桌面版及 webOS 测试包使用同一版本号。

标准版：`hongguo-tv-0.2.76.apk`（versionCode 77）

MPV 版：`hongguo-tv-mpv-0.2.76.apk`（versionCode 29）

桌面版：`hongguo-desktop-0.2.76-macos-universal.zip`、`hongguo-desktop-0.2.76-windows-x64.zip`。

webOS：`hongguo-webos-0.2.76-test.1.ipk`，仍为实验包，尚未完成 LG 真机播放验证。

Android 两个 APK 可覆盖安装对应旧版本；标准版和 MPV 版保持独立更新渠道。桌面版 ZIP 需要完整替换程序目录，webOS 包需要通过 LG Developer Mode 安装。
