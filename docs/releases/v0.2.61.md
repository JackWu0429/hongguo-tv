# 红果短剧 v0.2.61

- 修复 MPV 版从找剧、排行榜、新剧、历史、收藏和点赞卡片进入播放时的换源生命周期问题。
- 切换播放源前先停止旧源，新源在收到 `FILE_LOADED` 后才开始播放，避免旧解码器和新源重叠。
- 隔离旧会话的延迟回调，避免旧源的结束、错误或进度事件污染当前卡片。
- 标准版继续使用 WebView + Media3，MPV 版继续使用内置 MPV 播放路径。
- 两个版本最低支持 Android 6，应用名称统一为“红果短剧”。

标准版：`hongguo-tv-0.2.61.apk`

MPV 版：`hongguo-tv-mpv-0.2.61.apk`
