# 红果短剧 v0.2.62

- 修复 Android TV 搜索输入框在部分旧版 WebView/系统输入法上抢走窗口焦点后，遥控器上、下键无法离开输入框的问题。
- 搜索框进入编辑态时，原生壳单独维护搜索编辑状态；上、下键继续交给网页焦点路由，左右键、删除、文字输入和确认键继续交给输入框。
- 返回键优先关闭系统输入法，离开搜索框、切页、全屏切换和 Activity 生命周期结束时清理编辑状态，避免焦点跳到“检查更新”等无关按钮。
- 增加对应的 Java 输入策略测试和浏览器遥控器回归测试；不按设备型号做黑名单，也不改变扫码输入和数字键盘路径。
- 保留本分支已确认的播放相关修复：卡片换源生命周期隔离，以及从已进入播放页/推荐页全屏状态下用上、下键切换上一集/下一集、左右键快进或后退。
- 标准版继续使用 WebView + Media3，MPV 版继续使用内置 MPV 播放路径；两个版本最低支持 Android 6，应用名称统一为“红果短剧”。

标准版：`hongguo-tv-0.2.62.apk`（versionCode 63）

MPV 版：`hongguo-tv-mpv-0.2.62.apk`（versionCode 15）
