# 红果短剧 v0.2.89

- 预约写入成功后不再连续读取预约列表等待确认，避免按钮长时间等待。
- 界面区分“红果已接受预约请求”和“预约列表已显示该剧”；未出现在列表时提示稍后刷新核对，不把未确认结果显示成成功，也不提前改本地预约状态。
- 增加简体中文、繁体中文和日文的待核实提示。

Android 标准版：`hongguo-tv-0.2.89.apk`（versionCode 90）。

Android MPV 版：`hongguo-tv-mpv-0.2.89.apk`（versionCode 42）。

macOS / Windows：`hongguo-desktop-0.2.89-macos-universal.zip`、`hongguo-desktop-0.2.89-windows-x64.zip`（desktop versionCode 28）。桌面版同步共享核心的预约状态反馈。

webOS：`hongguo-webos-0.2.89-test.11.ipk`，仍为实验包；尚未接入账号预约，也未完成 LG 真机验证。

自动化测试覆盖预约写入不触发列表回读，以及请求已接受但列表尚未确认时不更新本地预约状态。跨设备预约同步仍需使用真实红果账号实测；本次发布不声称已查明 Android 与桌面端上游行为不同的根因。
