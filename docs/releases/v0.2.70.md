# 红果短剧 v0.2.70

- 修复上游 `video_model` 对设备标识一次性放行导致的播放失败。
- 每次播放解析使用新的 `device_id/iid`，并让完整请求签名与本次设备身份保持一致。
- 空响应最多使用新的设备身份重试 3 次；明确的 HTTP、JSON 或视频源错误不会被重复隐藏。
- 标准版和 MPV 版共用同一套播放解析修复，保留原有解密、Range 和播放器路径。

标准版：`hongguo-tv-0.2.70.apk`（versionCode 71）

MPV 版：`hongguo-tv-mpv-0.2.70.apk`（versionCode 23）

可覆盖安装对应旧版本，无需卸载。实际播放仍受上游可用性和设备解码能力影响。
