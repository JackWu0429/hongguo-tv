# 红果短剧 v0.2.9

- 播放页新增真实点赞、评论和收藏计数：点赞与评论对应当前集，收藏对应整部剧，换集自动更新。
- 计数以“万 / 亿”简洁显示；缺失数据保留占位，读取失败不影响播放，迟到响应不会覆盖当前集。
- 新增打赏页面，微信与支付宝二维码并排展示；确认键可放大，返回后恢复原卡片焦点。
- 打赏页面不展示姓名或联系方式，二维码图片中的姓名文字已去除。
- 删除“我的 / 登录”中的下载代理说明，将相关入口改为“下载设置”。
- 修正 Android 登录输入框困住焦点的问题：确认键进入输入，返回键完成输入并移到按钮；关闭输入法也会恢复方向键导航。
- 保留原包名、固定签名与应用内更新，覆盖升级保留账号与观看记录。

最低 Android 6，支持 ARM64、ARMv7 和 x86_64。
