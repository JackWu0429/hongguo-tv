红果短剧 v0.2.50

- MPV 版默认自动解码，参考 MiniReel 的 auto-safe 策略尝试硬件加速，降低持续播放的 CPU 开销。
- “我的 → 播放解码”可切换自动解码和软件解码；选择会保存，下次播放或切集时生效。自动模式画面异常时，可使用软件模式。
- MPV 采用较轻的画面缩放配置，保留已有声音、Surface 和全屏处理。
- 播放诊断新增实际解码路径、解码/渲染掉帧和可用的音画差值，避免把设置值误当成实际硬解结果。
- 标准版仍使用原有 WebView + Media3；两版保持独立包名、数据和更新渠道。

标准版：`hongguo-tv-0.2.50.apk`

MPV 版：`hongguo-tv-mpv-0.2.50.apk`

已安装的同版 APK 可以直接覆盖升级。MPV 用户可先用自动模式比较同一集的流畅度，若出现画面异常，在“我的”改为软件解码后重新播放。实际盒子播放效果仍需设备验证。
