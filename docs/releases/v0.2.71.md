# 红果短剧 v0.2.71

- 播放控制栏重新整理：弹幕开关移到全屏按钮左侧，两者保持同一组显示，不增加分隔线。
- 弹幕按钮默认只显示图标，获得焦点时在右侧显示“弹幕开/弹幕关”，并用不同 SVG 表示开关状态。
- 保留 v0.2.70 的播放解析修复和 Media3 1.8.0 更新：标准版继续 WebView 优先、Media3 回退；MPV 版保持独立播放路径。
- 补齐旧 Android WebView 的控制栏间距兼容规则，保持遥控器焦点顺序为诊断 → 弹幕 → 全屏。

标准版：`hongguo-tv-0.2.71.apk`（versionCode 72）

MPV 版：`hongguo-tv-mpv-0.2.71.apk`（versionCode 24）

可覆盖安装对应旧版本，无需卸载。实际播放仍受上游可用性和设备解码能力影响。
