# 红果短剧 v0.2.64

- WebView 播放改为按需读取视频数据，减少切集前的整集下载等待；下一集预取只准备播放地址和索引，不预下载媒体内容。
- Range 请求遇到短暂断网或连接中断时，从已接收位置继续请求；签名地址刷新后校验视频身份，避免接错内容。
- 不支持按需读取的媒体、播放错误或持续卡住时，自动回退到标准完整文件播放。
- 同剧切集保留当前画面；切换很快时不闪出加载提示，较慢时再显示。
- 切换清晰度时清理旧的卡顿监测计时器，避免旧计时影响新画质。
- MPV 版继续走原有完整文件播放路径。

标准版：`hongguo-tv-0.2.64.apk`（versionCode 65）

MPV 版：`hongguo-tv-mpv-0.2.64.apk`（versionCode 17）

按需读取的 Android TV 真机验证仍需继续；遇到兼容问题时，前台播放会回退到标准模式。
