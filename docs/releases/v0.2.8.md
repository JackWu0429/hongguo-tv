# 红果短剧 v0.2.8

- “我的”提供当前版本、检查更新和下载代理设置；启动后每天最多自动检查一次，播放期间不弹窗。
- 新版本展示更新内容，可选择立即更新或稍后。默认 ghfast 下载，失败时尝试 GitHub 直连；下载显示进度，可取消。
- 完善升级容错：拒绝陈旧或不一致版本信息，备用源仍无有效结果时提示重试；断流和坏文件不复用，失败后可重新下载。
- 安装前校验文件大小、SHA256、包名、实际版本和同一签名。系统确认安装，覆盖升级保留账号、收藏和历史。
- 正式 APK 和版本信息通过独立公开下载仓库发布，源码保持私有。

最低 Android 6，支持 ARM64、ARMv7 和 x86_64。当前未安装带更新功能的版本时，本版本需要先手动覆盖安装一次。
