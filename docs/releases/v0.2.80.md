# 红果短剧 v0.2.80

- 增强手机号登录的失败兜底：短信验证码发送失败时，仍保留已注册的登录会话，允许用户从手机红果 App 获取验证码后回到电视或桌面端完成登录。
- 保留大陆及其他地区的国家/地区号选择、手机号规范化和现有短信登录流程。
- Android 标准版和 MPV 版、macOS / Windows 桌面版及 webOS 测试包统一使用 `0.2.80`。

标准版：`hongguo-tv-0.2.80.apk`（versionCode 81）

MPV 版：`hongguo-tv-mpv-0.2.80.apk`（versionCode 33）

桌面版：`hongguo-desktop-0.2.80-macos-universal.zip`、`hongguo-desktop-0.2.80-windows-x64.zip`（desktop versionCode 19）。

webOS：`hongguo-webos-0.2.80-test.3.ipk`，仍为实验包，尚未完成 LG 真机播放验证。

自动化测试通过。海外手机号登录的真实上游可用性仍需要对应国家/地区的真实设备和号码验证。
