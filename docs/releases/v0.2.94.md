# 红果短剧 v0.2.94

- 同一部剧切换集数时，使用目标集首帧图作为 loading 底图；MPV、Media3 和 HTML5 播放共用该过渡效果，真实视频画面就绪后撤掉底图。
- 接口未返回首帧图、图片加载失败或请求失效时，沿用黑色过渡，不影响播放首帧和声音交接。

Android 标准版：`hongguo-tv-0.2.94.apk`（versionCode 95）。

Android MPV 版：`hongguo-tv-mpv-0.2.94.apk`（versionCode 47）。

macOS / Windows：`hongguo-desktop-0.2.94-macos-universal.zip`、`hongguo-desktop-0.2.94-windows-x64.zip`（desktop versionCode 33）。

Linux x86_64 AppImage 测试版：见公开下载仓库的 `linux-v0.2.94-test.1`；仅验证 Ubuntu 24.04 和 Debian 12 容器环境，依赖系统 WebKitGTK/GStreamer，不能代表所有发行版或实体硬件。
