观看历史新增「全部 / 未看完 / 已看完」筛选。

- 标题下方使用圆角筛选按钮，粉色表示当前筛选，白框表示遥控器焦点。
- 最后一集播放结束后归入「已看完」；只进入最后一集、看完中间集及缺少结束标记的旧云端记录归入「未看完」。多季短剧按当前这部/这一季判断。
- 筛选后的列表继续支持滚动加载，返回播放前的筛选及卡片焦点；空列表也可用方向键切换筛选。
- 筛选只改变显示，不修改账号或观看记录，收藏和点赞保持原来的展示。

最低 Android 6，使用原正式签名，可覆盖升级并保留账号和记录。106 项 JavaScript 回归、12 项发行检查及旧 WebView 布局/焦点模拟通过；Android 6 实机请覆盖安装检查。
