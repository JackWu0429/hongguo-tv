# 红果短剧 v0.2.106

## 更新

- 播放页首次从推荐进入并开始播放时，Android TV 与 webOS 显示遥控器菜单操作提示。
- 提示图使用 SVG 资源，文字随当前语言显示，按播放视口等比例缩放；按返回键或菜单键后关闭，不影响实际播放菜单和焦点操作。
- 保留 v0.2.105 已完成的 Android 搜索输入焦点、联想面板和返回键修复。

## 平台包

- Android 标准版：`hongguo-tv-0.2.106.apk`（versionCode 107）
- Android MPV 版：`hongguo-tv-mpv-0.2.106.apk`（versionCode 59）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.106-macos-universal.zip`、`hongguo-desktop-0.2.106-windows-x64.zip`（versionCode 45）
- Linux x86_64 AppImage 测试版
- LG webOS 实验版

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 与 webOS 仍属于平台测试包，实际兼容性取决于目标设备运行库、解码能力和型号。
