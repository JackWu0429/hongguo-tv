# 红果短剧 v0.2.108

## 修复

- 播放页菜单键兼容 Android TV 标准菜单键、TV 内容菜单键和 TV 媒体上下文菜单键，统一打开应用内播放侧栏。
- 播放侧栏打开后默认把焦点放到“选集”，返回键关闭侧栏并恢复播放器焦点。
- 遥控器菜单引导在大视口下使用稳定的可读字号，避免 SVG 缩放后文字过小。
- 保留 Android 6/7.1 兼容路径，不引入依赖新系统 Channel API 的安装要求。

## 平台包

- Android 标准版：`hongguo-tv-0.2.108.apk`（versionCode 109）
- Android MPV 版：`hongguo-tv-mpv-0.2.108.apk`（versionCode 61）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.108-macos-universal.zip`、`hongguo-desktop-0.2.108-windows-x64.zip`（versionCode 47）
- Linux x86_64 AppImage 测试版
- LG webOS 实验版

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 与 webOS 仍属于平台测试包，实际兼容性取决于目标设备运行库、解码能力和型号。
