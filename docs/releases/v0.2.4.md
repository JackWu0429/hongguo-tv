修复 Android 6 登录、圆角焦点和栏目布局，并补全新剧日历的全天内容。

- 我的预约：未登录时的登录按钮放回空态框内并居中，方向键可直接进入。
- 卡片和按钮：使用跟随圆角的焦点高亮，兼容旧 WebView。
- 新剧日历：从当天已上线内容开始，使用两个独立的官方分页游标加载全部已上线与待上线剧集；已上线显示播放，待上线显示预约。
- 排行榜：筛选项自动换行，移除固定高度裁切，焦点移动时滚动至可见区域。
- 短信登录：上下键复用页面焦点路由，手机号可移至获取验证码、验证码可移至登录；保留系统输入法和左右编辑，离开输入框时收起键盘。
- 启动页：文字和版本号上方增加旋转矢量动画，后台、启动失败或进入页面后停止。

正式签名，版本 0.2.4，versionCode 6，支持 Android 6 及以上和三种架构，与此前正式版本使用同一签名，可覆盖升级并保留账号数据。

验证：23 项 JavaScript 测试、Go race/vet、1280×720 / 1920×1080 旧 WebView API 模拟通过；真实账号只读日历回归确认同时返回当天已上线与待上线内容。实际 Android 6 输入法、焦点边缘和原生启动动画仍需设备复测。
