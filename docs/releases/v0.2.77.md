# 红果短剧 v0.2.77

- 恢复选集弹窗中的剧集详情、海报和演员列表；演员可进入作品列表，返回键可回到播放界面。
- 修复详情弹窗关闭按钮位置，避免被收藏和追更操作挤到下方。
- 修复收藏、追更成功后弹窗内状态不能立即刷新的问题。
- 修复繁体中文和日文切换后的核心服务状态文案刷新问题，并保留选集页的本地化布局。
- Android 标准版和 MPV 版、macOS / Windows 桌面版及 webOS 测试包使用同一版本号。

标准版：`hongguo-tv-0.2.77.apk`（versionCode 78）

MPV 版：`hongguo-tv-mpv-0.2.77.apk`（versionCode 30）

桌面版：`hongguo-desktop-0.2.77-macos-universal.zip`、`hongguo-desktop-0.2.77-windows-x64.zip`。

webOS：`hongguo-webos-0.2.77-test.1.ipk`，仍为实验包，尚未完成 LG 真机播放验证。

Android 两个 APK 可覆盖安装对应旧版本；标准版和 MPV 版保持独立更新渠道。桌面版 ZIP 需要完整替换程序目录，webOS 包需要通过 LG Developer Mode 安装。

本版本已从同一发布提交构建。后续正式版本统一从正式线的 `vX.Y.Z` 标签触发各平台构建；桌面和 webOS 的手动触发仅用于补发或测试。
