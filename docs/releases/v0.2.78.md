# 红果短剧 v0.2.78

- 修复部分旧版 Android TV WebView 从找剧、排行榜、历史、收藏等页面点击视频时的渲染进程闪退风险：播放加载面板延后一帧显示，避免与列表切换到播放布局同时提交。
- loading 状态的快速切换会丢弃过期显示回调；失败提示仍即时显示。
- Android 标准版和 MPV 版、macOS / Windows 桌面版及 webOS 测试包统一使用 `0.2.78`。

标准版：`hongguo-tv-0.2.78.apk`（versionCode 79）

MPV 版：`hongguo-tv-mpv-0.2.78.apk`（versionCode 31）

桌面版：`hongguo-desktop-0.2.78-macos-universal.zip`、`hongguo-desktop-0.2.78-windows-x64.zip`（desktop versionCode 17）。

webOS：`hongguo-webos-0.2.78-test.2.ipk`，仍为实验包，尚未完成 LG 真机播放验证。

本版本的自动化测试通过。修复针对报告中的旧版 WebView 闪退时序，仍需出问题的电视型号实机复测；不代表所有电视上的闪退都已解决。
