# 红果短剧 v0.2.107

## 修复

- 修复 Android TV 与 webOS 推荐首页自动播放第一条视频时，没有显示遥控器菜单按键引导的问题。
- 仅在推荐内容已载入且视频实际开始播放后显示一次提示；播放失败时不抢先显示。
- 保留 v0.2.106 播放菜单 SVG 多语言提示、菜单键入口和既有 Android 搜索焦点修复。

## 平台包

- Android 标准版：`hongguo-tv-0.2.107.apk`（versionCode 108）
- Android MPV 版：`hongguo-tv-mpv-0.2.107.apk`（versionCode 60）
- macOS / Windows 桌面版：`hongguo-desktop-0.2.107-macos-universal.zip`、`hongguo-desktop-0.2.107-windows-x64.zip`（versionCode 46）
- Linux x86_64 AppImage 测试版
- LG webOS 实验版

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 与 webOS 仍属于平台测试包，实际兼容性取决于目标设备运行库、解码能力和型号。
