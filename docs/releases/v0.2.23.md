精简播放页操作和选集面板，并修复切换页面后的残留背景。

- 点赞、收藏、评论只显示图标与真实数量，保留选中状态和焦点高亮。
- 选集面板移除海报、重复简介及播放/收藏按钮，保留剧名、选集/系列剧、当前集与总集数，增加可见集数区域。
- 打开时定位正在播放的集数，支持向上返回标签、切换系列剧和关闭后返回原按钮；异步数据不抢走已移动的焦点。
- 集数读取失败可以原地重试，无可播放集数时显示明确提示。
- 排行榜、找剧等页面彻底隐藏播放区域，避免顶部透出上一部剧的视频或海报。
- 核对关注、漫剧、真人剧、推荐的频道参数，均与红果接口返回的频道名称一致。

最低 Android 6，使用原正式签名，可覆盖升级。101 项 JavaScript 回归、12 项发行检查与旧 WebView 布局/焦点模拟通过；Android 6 实机视觉与遥控操作需覆盖安装复测。
