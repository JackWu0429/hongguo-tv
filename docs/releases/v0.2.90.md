# 红果短剧 v0.2.90

- MPV 播放使用可恢复的 Range/CENC 媒体代理，并在适用时预取紧邻下一集的开头；Range 不可用、媒体错误或预取失败时，在真正播放时保留完整文件下载/解密兜底。
- MPV 切集过渡使用上游返回的本集封面，减少切集时的空白过渡。
- 增加播放准备、预取交接、Range 初始化和 MPV 切集时序诊断，便于定位不同设备上的等待时间；这些字段记录时序，不代表已证明某个设备存在掉帧或卡顿。

Android 标准版：`hongguo-tv-0.2.90.apk`（versionCode 91）。

Android MPV 版：`hongguo-tv-mpv-0.2.90.apk`（versionCode 43）。

macOS / Windows：`hongguo-desktop-0.2.90-macos-universal.zip`、`hongguo-desktop-0.2.90-windows-x64.zip`（desktop versionCode 29）。

webOS：`hongguo-webos-0.2.90-test.12.ipk`，仍为实验包；尚未完成 LG 真机验证。

自动化测试覆盖 Range 播放策略、预取失败回退、MPV 切集封面过渡和时序诊断。真实设备上的 MPV 弹幕性能仍需设备数据验证。
