# 红果短剧 v0.2.104

## 修复

- 修复 Android 搜索输入法交接后，遥控器方向键无法继续操作搜索联想列表的问题。
- 修复搜索联想面板与系统返回键交互异常的问题；键盘收起后会恢复联想项焦点，返回操作留在应用内处理。

## 平台包

- Android 标准版与 MPV 版
- macOS 与 Windows 桌面版
- Linux x86_64 AppImage 测试版
- LG webOS 实验版

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 在 Ubuntu 24.04 与 Debian 12 容器中验证真实数据和视频播放；其他发行版及本地硬件解码仍取决于系统运行库与设备。

webOS 包仍是实验版，尚未通过 LG 真机验证。
