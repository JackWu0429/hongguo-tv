# 红果短剧 v0.2.81

- 优化手机号登录失败提示：同时显示具体错误原因、错误码和手机红果 App 取码说明，不再互相覆盖。服务端没有给出具体原因时明确提示，并保留可用错误码。
- 修复繁体中文、日文下登录错误被简化为通用提示的问题，保留原始错误详情，方便排查。
- 按 hongguo-player v1.2.4 实际 macOS 包核对并适配非大陆手机号的号码编码、独立签名和二次验证流程，修正部分地区号码长度限制。
- 发码失败后保留验证码输入入口；可尝试使用手机红果 App 获取的同手机号验证码继续登录。
