# 红果短剧 v0.2.101

- 修复 Media3 切集时回退到 WebView 准备下一集期间旧剧集海报重新出现的问题。实际切集空白时长仍可能因设备和视频源不同而异。
- 修复部分 Android TV 搜索输入框无法恢复渲染层焦点的问题，并抑制软键盘收起后的短时焦点回声。
- 调整宽视口搜索联想面板，使其按当前可见的搜索控件区域显示；修正 Android 6 联想列表中的图标资源和尺寸。
- 修复 webOS 构建脚本对未声明 `rg` 命令的依赖。

Android 标准版：`hongguo-tv-0.2.101.apk`（versionCode 102）。

Android MPV 版：`hongguo-tv-mpv-0.2.101.apk`（versionCode 54）。

macOS / Windows：`hongguo-desktop-0.2.101-macos-universal.zip`、`hongguo-desktop-0.2.101-windows-x64.zip`（desktop versionCode 40）。Windows HEVC 播放需要安装 HEVC Video Extensions；未在 Windows 实机验证播放。

Linux x86_64 AppImage 测试版：见公开下载仓库的 `linux-v0.2.101-test.1`；使用同一 AppImage 在 Ubuntu 24.04 与 Debian 12 容器验证播放，依赖系统 WebKitGTK/GStreamer，不代表实体硬件或其他发行版。

webOS：`hongguo-webos-0.2.101-test.23.ipk`，仍为实验包。尚未完成 LG 真机上的数据连接和播放验证。
