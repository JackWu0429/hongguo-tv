# 红果短剧 v0.2.103

## 修复

- 修复 Android 搜索输入法接管焦点后，遥控器方向键无法继续操作联想搜索列表的问题。
- 修复搜索联想交互中的返回键被输入法或系统吞掉、导致直接离开应用的问题；现在优先在应用内完成编辑退出和页面返回。

## 平台包

- Android 标准版与 MPV 版
- macOS 与 Windows 桌面版
- Linux x86_64 AppImage 测试版
- LG webOS 实验版

Windows 播放 HEVC 视频需要安装 HEVC Video Extensions：<https://github.com/Ayx03/HEVCVideoExtension>。

Linux AppImage 已在 Ubuntu 24.04 与 Debian 12 容器中验证真实数据和视频播放；其他发行版及本地硬件解码仍取决于系统运行库与设备。

webOS 包仍是实验版，尚未通过 LG 真机验证。
