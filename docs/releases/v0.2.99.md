# 红果短剧 v0.2.99

- Media3 切集时继续显示目标集首帧图，直到视频时间实际推进，再用约 180ms 淡出，避免首帧回调早于电视实际显示画面而短暂黑屏。
- 统一观看历史、收藏、点赞和追更标题与说明的间距，并避免 Android 6 下剧集简介末行被裁切。
- 更新微信与支付宝打赏二维码图片，并隐藏支付宝码中的个人信息。

Android 标准版：`hongguo-tv-0.2.99.apk`（versionCode 100）。

Android MPV 版：`hongguo-tv-mpv-0.2.99.apk`（versionCode 52）。

macOS / Windows：`hongguo-desktop-0.2.99-macos-universal.zip`、`hongguo-desktop-0.2.99-windows-x64.zip`（desktop versionCode 38）。

Linux x86_64 AppImage 测试版：见公开下载仓库的 `linux-v0.2.99-test.1`；发布前通过 Ubuntu 24.04 与 Debian 12 容器中的播放验证。

webOS：`hongguo-webos-0.2.99-test.21.ipk`，仍为实验包；尚未完成 LG 真机验证。
