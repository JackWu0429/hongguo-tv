# 红果短剧 v0.2.74

- 手机号登录支持中国大陆、中国香港、中国澳门、中国台湾及多个东南亚、日韩和阿联酋地区；国家/地区选择支持电视遥控器焦点和扫码输入，默认仍为中国大陆 `+86`。
- 登录请求按所选地区规范化国际号码，并保留旧版中国大陆号码调用兼容；号码显示使用脱敏格式。
- 排行榜中的演员入口可以打开演员作品列表，支持继续浏览和播放作品。
- 保留上一版的连续切集、播放恢复、相关推荐和榜单雷达改进。

标准版：`hongguo-tv-0.2.74.apk`（versionCode 75）

MPV 版：`hongguo-tv-mpv-0.2.74.apk`（versionCode 27）

桌面版：`hongguo-desktop-0.2.74-macos-universal.zip`、`hongguo-desktop-0.2.74-windows-x64.zip`。

webOS：`hongguo-webos-0.2.74-test.1.ipk`，仍为实验包，尚未完成 LG 真机播放验证。

Android 两个 APK 可覆盖安装对应旧版本；标准版和 MPV 版保持独立更新渠道。桌面版 ZIP 需要完整替换程序目录，webOS 包需要通过 LG Developer Mode 安装。
