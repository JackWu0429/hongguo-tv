# 红果短剧 v0.2.6

- 正式版应用名称改为“红果短剧”，保留播放标志，启动图标使用圆角背景。
- 侧栏图标增大至 32px，文字增大至 20px；调整窄屏侧栏宽度，登录项保持单行。
- 右侧弹幕按钮向下可到全屏，全屏向上返回弹幕；进度条焦点改为当前位置圆点，左右快进快退保留。
- “已连接”前新增小型 SVG 连接图标，根据连接状态显示颜色。
- 补齐核心重启后的残留媒体缓存回收，保留运行中的核心目录；旧版无标记缓存到期后回收。

正式签名 APK 可覆盖升级 v0.2.5，保留账号与记录。最低 Android 6，支持 arm64-v8a、armeabi-v7a、x86_64。

保留约 512 MiB 的完成文件清理阈值；下载和解密中的文件可能让占用短暂超过阈值。

Go race/vet、32 项 JavaScript 测试、缓存清理测试及旧 WebView 模拟验证通过。真实 Android 6 的桌面图标、遥控器和长期播放效果仍需设备复测。
