红果短剧桌面版 0.2.81（macOS / Windows）

- 登录发码失败时，同时显示具体错误及手机红果 App 取码说明；繁体中文和日文也保留错误详情与错误码。
- 非大陆手机号按实际参考包适配号码编码、签名和二次验证，修正部分地区的输入长度限制。
- 发码失败后保留输入入口，允许尝试提交手机红果 App 获取的同手机号验证码。
- 尚无真实境外号码端到端成功记录，协议与隔离测试通过不等于所有地区都能登录成功。

macOS 通用 ZIP 支持 Intel / Apple Silicon，最低 macOS 11；Windows x64 需要 Microsoft Edge WebView2 Runtime。
通过设置检查更新并下载 ZIP，退出后手动替换完整程序。账号及本地记录保存在独立用户目录。
