红果短剧桌面版 0.2.71（macOS / Windows）

- 修复相关推荐关闭后的焦点：显示底部控件，并高亮“选集”按钮；保持当前播放页和全屏状态。
- 相关推荐展示就绪后，首张卡片右上角显示纯数字的 30 秒倒计时，无操作则自动播放第一张并沿用历史续播。
- 移焦、方向键、鼠标/触摸浏览、关闭或返回都会取消倒计时，回到首张不重启；切后台、窗口失焦、切页面/剧集/账号也会取消。
- 播放控制栏将弹幕开关放到全屏按钮左侧，默认显示图标，聚焦时显示状态文字；两者之间不增加分隔符。
- macOS 通用 ZIP 支持 Intel / Apple Silicon，最低 macOS 11；Windows x64 需要 Microsoft Edge WebView2 Runtime。
- 桌面版通过独立更新清单检查并下载 ZIP，安装仍由用户手动替换程序文件。
- 未做 Apple 公证或 Windows 代码签名。
