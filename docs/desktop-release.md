红果短剧桌面版 0.2.79（macOS / Windows）

- 恢复选集弹窗中的剧集详情、海报和演员列表；演员可进入作品列表，返回键可回到播放界面。
- 修复详情弹窗关闭按钮位置，以及收藏、追更成功后的即时状态刷新。
- 修复侧边栏顶部“推荐”项目的焦点框被裁切，完整显示焦点高亮。
- 修复切换繁体中文或日文后，顶部核心服务状态仍显示旧语言的问题。
- 调整播放加载面板的显示时序，避免播放布局切换和面板显示落在同一帧提交。
- 修复旧版 WebView 对禁用页面标题按钮使用原生白色外观，导致左上角出现白块的问题。
- macOS 通用 ZIP 支持 Intel / Apple Silicon，最低 macOS 11；Windows x64 需要 Microsoft Edge WebView2 Runtime。
- 桌面版使用系统 HTML5 播放，HEVC 视频是否能正常显示取决于系统与硬件。macOS 已实测真实播放和自动下一集，Windows 实体播放仍待实测。
- 桌面版通过独立更新清单检查并下载 ZIP，安装仍由用户手动替换程序文件。
- 未做 Apple 公证或 Windows 代码签名。
