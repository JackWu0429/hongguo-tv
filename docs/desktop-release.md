红果短剧桌面版 0.2.99（macOS / Windows）

- Media3 切集时保留下一集首帧封面，直到播放时间推进后淡出，避免真实画面尚未显示就露出黑屏。
- 统一观看历史、收藏、点赞和追更标题与说明的间距，并避免 Android 6 下剧集简介末行被裁切。
- 更新微信与支付宝打赏码图片；支付宝图片中的个人信息已隐藏。

macOS 通用 ZIP 支持 Intel / Apple Silicon，最低 macOS 11；Windows x64 需要 Microsoft Edge WebView2 Runtime。Linux x86_64 AppImage 测试版在独立的 `linux-v0.2.99-test.1` 预发行版中提供，依赖系统 WebKitGTK 和 GStreamer。
通过设置检查更新并下载 ZIP，退出后手动替换完整程序。账号及本地记录保存在独立用户目录。
未做 Apple 公证或 Windows 代码签名。Windows 实体播放仍待实测。
