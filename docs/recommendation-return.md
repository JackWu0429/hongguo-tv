# 推荐栏目的返回与刷新

0.2.32 起，本次应用启动内从其他导航返回推荐时，保留离开前的频道、已加载列表、当前剧和列表位置，并恢复集数与观看进度。顶部“换一批”主动重新请求当前频道；选择频道或重新启动应用也重新获取推荐。

推荐快照独立于其他页面的单剧播放器，后者不能覆盖推荐列表。只保存当前频道的一份内存快照，不写磁盘，不增加视频下载或媒体缓存。分页控制器保留原游标、去重集合和未展示缓冲；离开时取消请求并增加代次，迟到的分页或播放响应不能更新其他页面。

离开前捕获真实播放位置；正在解析时捕获请求中的目标集和续播位置，不使用旧视频时钟。返回等待已有历史写入完成，再选择续播位置。自己的离开保存进入历史基线；之后同剧观看记录变化，则使用最新记录，即使是用户主动重看较早的一集。收藏、点赞等其他字段变化不算进度变化。保存失败时仍能用内存捕获的位置恢复，但不宣称历史已保存成功。已完成集沿用既有历史续播规则。

切换账号立即丢弃旧推荐快照；返回时还核对账号代次、频道和列表索引。点击已经打开的推荐导航仅恢复焦点，不重启播放。初次列表尚未取得、刷新失败或空列表没有可恢复内容时仍按正常加载处理。

验证覆盖推荐往返、跨页播放另一部和同剧进度更新、保存延迟与失败、解析中离开与迟到响应、分页游标与取消、主动刷新、账号及频道隔离；旧 WebView 浏览器模拟与正式 APK 构建不等于 Android 6 实机验收。
